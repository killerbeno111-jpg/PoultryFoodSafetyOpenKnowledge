# 🐔 Poultry Food Safety Open Knowledge

An offline Android reference app for poultry food safety learning.

## What changed from the academy version

- No certification course structure
- No levels/prerequisites
- No quizzes or exams
- No scores or certificates
- No compulsory lesson completion
- Open any topic whenever you want
- Global offline search
- Bookmarks + personal learning notes stored locally
- 27-topic technical knowledge base retained
- Official-source reference section retained
- Educational calculators retained

## Android build

Open this folder in Android Studio and let Gradle sync. Then:

**Build → Build Bundle(s) / APK(s) → Build APK(s)**

The generated APK can then be installed on an Android phone.

## GitHub

Create a new GitHub repository and upload this project folder. The project is intentionally source-based so it can remain open source and be modified later.
